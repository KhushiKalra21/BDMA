# **MongoDB Movie Analytics: Query Optimization & Dashboard Development**  

## **Project Overview**  

This project explores **MongoDB’s capabilities** in **big data analytics and visualization** using a **comprehensive movies dataset**. The project is structured in two phases:  

1. **Phase 1: Query Execution in MongoDB Compass**  
   - CRUD Operations, Find Queries, Filtering, Aggregation  

2. **Phase 2: Dashboard Development in MongoDB Atlas**  
   - Interactive data visualizations using MongoDB Charts  

By leveraging **NoSQL features, aggregation pipelines, and real-time dashboards**, this project **unlocks hidden insights** into **genre trends, director success patterns, rating distributions, and more**.  

---

## **Project Files & Structure**
